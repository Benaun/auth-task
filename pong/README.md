# ASCII Pong на языке C

Простая пошаговая игра для двух игроков, похожая на Pong.
Графика выводится в терминал обычными ASCII-символами.

## Ограничения

- Используется только стандартная библиотека C.
- Нет вызовов `system()` и похожих функций.
- Поле: 80 на 25 символов.
- Размер ракетки: 3 символа.
- Размер мяча: 1 символ.
- Игра идет до 21 очка.

## Управление

- `A` - поднять левую ракетку вверх.
- `Z` - опустить левую ракетку вниз.
- `K` - поднять правую ракетку вверх.
- `M` - опустить правую ракетку вниз.
- `Space` - пропустить ход.

После ввода команды нужно нажать `Enter`, потому что программа использует стандартный ввод.

## Запуск

```bash
cd pong
make
./pong
```

Очистить собранный файл:

```bash
make clean
```

## Архитектура проекта

```text
pong/
  main.c     - весь код игры: состояние, ввод, движение, отрисовка, победа
  Makefile   - простая сборка через gcc
  README.md  - описание проекта, запуск, задачи команды
```

Проект специально сделан простым:

- Все константы находятся в начале `main.c`.
- Состояние игры хранится в обычных глобальных переменных.
- Отрисовка поля выполняется функцией `draw_field`.
- Ввод команды выполняется функцией `read_command`.
- Передвижение ракеток выполняется через `apply_command`.
- Движение мяча, отскоки и начисление очков находятся в `move_ball`.
- После счета 21 выводится победитель и программа завершается.

## Задачи для 3 разработчиков

### Разработчик 1: поле и отрисовка

- Сделать константы размера поля 80 на 25.
- Реализовать вывод границ поля.
- Нарисовать ракетки размером 3 символа.
- Нарисовать мяч размером 1 символ.
- Вывести счет игроков над полем.

### Разработчик 2: управление игроками

- Реализовать чтение команды через стандартный ввод.
- Проверять, что введены только `A`, `Z`, `K`, `M` или `Space`.
- Сделать движение левой ракетки по `A/Z`.
- Сделать движение правой ракетки по `K/M`.
- Запретить выход ракеток за границы поля.

### Разработчик 3: логика мяча и завершение игры

- Реализовать движение мяча по шагам.
- Сделать отскок мяча от верхней и нижней границы.
- Сделать отскок мяча от ракеток.
- Начислять очки, если игрок пропустил мяч.
- После 21 очка вывести поздравление победителю и завершить игру.
